# CertCenter 使用指南

CertCenter 按域名组织证书。管理员添加域名及所有者邮箱；所有者和管理员可以查看该域名的证书、修改策略、发起签发和部署。其他用户不能读取或操作该域名。

## 签发流程

1. 管理员在“设置”页配置 ACME，在“DNS 服务商”和“部署上游”页面添加账号，见 [配置指南](/docs/config)。默认使用 Let's Encrypt 生产目录；测试时可手动切换 staging，测试证书不受浏览器信任。
2. 进入“域名”，添加 `example.com`，设置所有者邮箱。
3. 在域名页添加证书策略，例如标识 `wildcard`，域名填写 `example.com` 和 `*.example.com`（换行或逗号分隔），选择 DNS provider。
4. 使用本项目内置 CNAME 验证时，管理员先按[配置指南](/docs/config)启用公网验证 DNS。用户只需在原 DNS 服务商处添加页面生成的 CNAME，并点击“检查 CNAME”；无需注册凭据或 JSON。
5. 在“更多”中选择签发并确认。任务在后台运行；“操作日志”显示进度，“证书历史”保留每次签发版本和有效期。
6. 配置上游后可以手工部署，或启用自动部署。云上游复用当前版本已保存的上传回执；SSH 手工部署仍会重新写入文件并执行重载。自动部署只处理未完成目标。

## 续期与重试

启用自动续签后，尚无证书的策略会自动签发。已有证书进入提前续签窗口时排队续签，窗口为策略天数和有效期三分之一的较小值；默认策略为 30 天。

调度器每分钟检查一次，同一策略只允许一个排队或运行任务。签发失败不会删除旧证书；上传部分失败会保留证书与成功回执，自动部署一小时后只重试未完成目标。自动部署独立于自动续签开关。

停用策略会阻止尚未开始的操作及后续自动任务；已开始的外部调用不会被强制撤回。页面每十秒刷新，在编辑对话框打开时暂停刷新。

## 部署含义

腾讯云和阿里云默认上传证书到 SSL/CAS 证书库。管理员可在“部署上游”编辑对话框开启“更新已绑定的云资源”：首次上传后在云控制台完成绑定，后续签发部署时会把本策略旧证书的现有绑定迁移到新证书。仅提交云端任务不算成功，系统会持续检查实际更新结果。

开启“删除已替换的云端证书”后，全部更新成功且检查无剩余绑定时才清理旧云端证书；更新失败、权限不足或绑定未解除时保留旧证书。只处理本项目记录过的旧上传，保留本地证书历史。阿里云还需填写部署联系人 ID，并准备上传证书所需的部署次数，详见[配置指南](/docs/config)。

SSH 使用 SFTP 写入证书和私钥，限制权限为 `0600`，然后运行可选的重载命令。SSH 凭据、固定主机公钥、路径和命令可在“部署上游”页面的编辑对话框中管理。

DNS 服务商支持阿里云、腾讯云、Cloudflare，以及本项目内置 acme-dns CNAME 验证；部署上游支持腾讯云、阿里云及 SSH。账号保存后可在证书策略中选择，已有密钥留空表示保留，被策略引用的账号不能删除。

设置页可直接编辑服务参数、ACME、CNAME 委派验证、OAuth、注册权限和数据库，保存后提示生效方式，无需跳转到 ConfigCenter。页面 API 不返回 DNS 凭据、云密钥、SSH 私钥、证书私钥或 ACME 账户私钥。
